# ClaudeGuard для Claude Desktop на macOS

ClaudeGuard направляет Claude Desktop через выбранный прокси и проверяет его выходной IPv4. LuLu ограничивает исходящие соединения Claude. После настройки Claude открывается обычной иконкой в Dock или Finder, пока ClaudeGuard работает в фоне.

## Что понадобится

- **Mac с macOS 14 или новее** на Apple Silicon или Intel и доступ администратора для установки.
- **Claude Desktop** в папке «Программы» (`/Applications/Claude.app`). [Скачать Claude у Anthropic](https://claude.com/download)
- **Свой прокси с постоянным публичным IPv4 на выходе.** Подойдёт SSH-сервер с поддержкой TCP forwarding, профиль VLESS/REALITY для Xray или внешний прокси. Выходной IPv4 — адрес, с которого прокси обращается к сайтам. У каскадного маршрута адрес входного сервера может отличаться от выходного IP.

## 1. Установите ClaudeGuard

1. Закройте Claude Desktop через **⌘Q**.
2. Откройте [релизы d6vmc/ClaudeGuard-Desktop](https://github.com/d6vmc/ClaudeGuard-Desktop/releases). В самом новом релизе **ClaudeGuard Desktop** откройте **Assets** и скачайте `ClaudeGuard-Desktop.pkg`.
3. Откройте пакет и подтвердите установку в том аккаунте macOS, из которого будете пользоваться ClaudeGuard. После установки откройте щит ClaudeGuard в строке меню. Для русского меню выберите **Language → Русский**.

Пакет Desktop содержит Python, прокси-движки, образ LuLu и файл правил. На чистом Mac для него достаточно графического установщика. Если в окне пакета видите общую памятку про Xcode Command Line Tools, она относится к обычной сборке. При переходе со старого пакета без встроенного Python установщик может запросить эти инструменты.

Если macOS сообщает, что разработчика пакета не удалось проверить, используйте **Конфиденциальность и безопасность → Всё равно открыть** только для пакета, скачанного из указанного релиза. В **Assets** релиза есть `ClaudeGuard-Desktop.pkg.sha256` для сверки контрольной суммы. [Инструкция Apple](https://support.apple.com/en-us/102445)

## 2. Установите LuLu и настройте правила из ClaudeGuard

LuLu работает как отдельное приложение. В ClaudeGuard 2.3.6 и новее автоматический импорт рассчитан на официальную LuLu 4.5.7 с видимым значком в строке меню.

1. В ClaudeGuard выберите **Защита → Настроить правила LuLu…** (*Protection → Set Up LuLu Rules…*). Если LuLu отсутствует, ClaudeGuard откроет образ. Перетащите `LuLu.app` в «Программы» и запустите LuLu оттуда. [Инструкция Objective-See](https://objective-see.org/products/lulu.html)
2. Подтвердите системное расширение и разрешите сетевой фильтр в запросе LuLu. На macOS 15 и новее расширение находится в **Системные настройки → Основные → Объекты входа и расширения → Сетевые расширения**. На macOS 14 следуйте подсказке LuLu в разделе «Конфиденциальность и безопасность». [Настройки расширений macOS](https://support.apple.com/guide/mac-help/mtusr003/mac)
3. Если ClaudeGuard попросит скорректировать активный профиль, в LuLu откройте **Settings → Rules** и выключите **Allow Localhost Traffic**, **Allow DNS Traffic** и **Allow Already Installed Programs**. В **Settings → Mode** выключите **Block Mode**, а в **Settings → Lists** отключите **Allow List**, если он включён.
4. Снова выберите **Настроить правила LuLu…**. При первом автоматическом импорте разрешите ClaudeGuard в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** и повторите команду. Подтвердите установку правил в ClaudeGuard. Приложение подготовит файл и запустит штатный импорт LuLu.
5. Закройте сообщение LuLu об импорте. ClaudeGuard проверит, что в активном профиле появились три правила для Claude Desktop. Постоянные правила других приложений сохраняются. Штатный импорт LuLu может сбросить временные правила. [Как работает импорт LuLu](https://objective-see.org/products/lulu.html)

Если ClaudeGuard не может управлять окном LuLu, он предложит подготовить объединённый файл. Оставьте текущий профиль активным и сразу выберите файл через **LuLu → Rules → Import**. Он включает постоянные пользовательские правила этого профиля.

Для другой версии LuLu доступен обычный ручной импорт. Чтобы сохранить существующие правила, создайте отдельный профиль через **LuLu → Settings → Profiles → Add Profile**. В ClaudeGuard выберите **Защита → Показать файл правил LuLu**, затем в меню значка LuLu выберите **Rules → Import** и укажите выделенный файл. Импорт заменяет пользовательские правила активного профиля. [Ручной импорт и профили](https://objective-see.org/products/lulu.html)

## 3. Подключите свой прокси

Откройте в ClaudeGuard раздел **Подключение** (*Connection*) и выберите один вариант. Поле **Expected exit IPv4** означает выходной IPv4 вашего прокси.

| Что у вас есть | Что выбрать и заполнить |
| --- | --- |
| SSH-сервер | **SSH-туннель…** (*SSH Tunnel…*). Укажите сервер, SSH-пользователя, порт, ожидаемый выходной IPv4 и SHA256-отпечаток **ключа сервера**. Возьмите отпечаток из доверенного источника, например у администратора сервера. При необходимости укажите путь к своему SSH-ключу. |
| Ссылка `vless://` для TCP/REALITY | **Импорт VLESS/REALITY…** (*Import VLESS/REALITY…*). Вставьте ссылку и укажите выходной IPv4. Чтобы Xray подключался к серверу через физическую сеть при смене профилей Happ, дополнительно укажите активный Wi-Fi или Ethernet-интерфейс, например `en0`, и IPv4 входного сервера. |
| Готовый внешний прокси | **Сторонний прокси…** (*External Proxy…*). Вставьте URL HTTP/SOCKS или поддерживаемый outbound JSON и укажите выходной IPv4. Для локального SOCKS, который предоставляет другой клиент, этот клиент должен быть запущен. |

При первом соединении LuLu может запросить разрешение для `ssh`, `xray`, `sing-box` или Happ. Разрешите соединение процесса, который обслуживает выбранный маршрут. Храните ссылку VLESS, пароль прокси и содержимое SSH-ключа у себя.

## 4. Включите маршрутизацию macOS

1. В ClaudeGuard откройте **Защита → Маршрутизация macOS…** (*Protection → macOS Proxy Routing…*).
2. Укажите имена используемых сетевых сервисов как в **Системные настройки → Сеть**. Например, `Wi-Fi` для Wi-Fi или `Wi-Fi, Happ`, если используете оба сервиса с такими именами. Сохраните настройки.
3. Если Happ уже подключён, переподключите его, чтобы активный туннель применил настройки. ClaudeGuard сохраняет PAC, который направляет через прокси домены Claude, Anthropic и hCaptcha. Он также применяется к этим доменам в браузерах, использующих системные настройки. [Сетевые требования Anthropic](https://support.claude.com/en/articles/18426225-move-from-claude-enterprise-to-claude-desktop-on-a-cloud-provider)

## 5. Проверьте первый запуск

1. В меню ClaudeGuard нажмите **Проверить соединение** (*Check Connection*). Дождитесь статуса **Защита активна** (*Protection active*) и сверьте IP в карточке с заданным выходным IPv4 прокси.
2. Откройте Claude из Dock либо кнопкой **Открыть Claude** (*Open Claude*). Войдите в аккаунт и проверьте, что Claude отвечает.
3. Если используете независимый маршрут Xray вместе с Happ, переключите сервер Happ и снова нажмите **Проверить соединение**. В карточке ClaudeGuard должен остаться заданный выходной IP прокси.
4. Для проверки реакции на обрыв сохраните работу в Claude и, если используете встроенный SSH или Xray, нажмите **Подключение → Отключить прокси**. ClaudeGuard должен закрыть Claude. Снова подключите прокси, дождитесь проверки IP и откройте Claude.

## Если что-то не работает

| Что видно | Что проверить |
| --- | --- |
| Щита ClaudeGuard нет в строке меню | Откройте **Программы → ClaudeGuard** из аккаунта, в котором установили пакет. |
| **Проверьте LuLu** | Активируйте сетевой фильтр и выберите **Защита → Настроить правила LuLu…**. ClaudeGuard проверит текущий профиль. |
| **Прокси не настроен**, **Прокси отключён** или **Соединение заблокировано** | Проверьте профиль, доступность сервера, разрешение LuLu для прокси-движка и ожидаемый **выходной** IPv4. Для отключённого встроенного туннеля выберите **Подключить прокси**. |
| **Маршрут macOS не активен** | Сохраните маршрутизацию для текущих сетевых сервисов и переподключите Happ, если он запущен. |
| Claude сообщает `Couldn't verify your browser` | Сохраните настройки маршрутизации и переподключите Happ, затем повторите обычный вход. Актуальный PAC включает hCaptcha. Если ошибка сохраняется, воспользуйтесь поддержкой Claude. |

## Обновления

С версии 2.3.7 команда **Проверить обновления…** находит релизы в текущем репозитории ClaudeGuard Desktop. Если установлена версия из предыдущего репозитория, скачайте `ClaudeGuard-Desktop.pkg` с этой страницы проекта и установите его поверх старой версии. Профиль прокси, маршрутизация и язык меню сохраняются. Следующие обновления можно ставить из меню.

## Удаление

1. Закройте Claude Desktop. В меню щита выберите **Удалить ClaudeGuard…** (*Uninstall ClaudeGuard…*). Подтвердите удаление и запрос администратора macOS.
2. Деинсталлятор остановит фоновые службы, очистит сетевые правила ClaudeGuard, восстановит прежний PAC там, где сейчас действует PAC ClaudeGuard, и удалит приложение, локальные данные, профили и настройки.
3. Если добавляли правила ClaudeGuard в LuLu, удалите эти три правила в LuLu или переключитесь на другой профиль. Это позволит Claude подключаться самостоятельно. LuLu и Happ работают как отдельные приложения.
